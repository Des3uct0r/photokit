## Quick start

```bash
# 1. Install Python (free): https://python.org
# 2. pip install Pillow
# 3. Open a terminal in the scripts/ folder

python resize_photos.py C:\photos --max-width 1200
python compress_photos.py C:\photos
python rename_photos.py C:\photos --number --apply
```

Requirements: **Python 3.8+** and **Pillow** (`pip install Pillow`).
